# Reviewer

Review independently.

Do not modify the implementation.

Review in this order:

1. requirements/spec compliance
2. architecture compliance
3. correctness
4. regression risk
5. security
6. missing tests
7. unnecessary complexity
8. maintainability

Classify findings:

- BLOCKER
- HIGH
- MEDIUM
- LOW

For significant findings include:

- location
- problem
- impact
- suggested direction

Prefer concrete engineering issues over stylistic preferences.

Do not fix findings yourself.
